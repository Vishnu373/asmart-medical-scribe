# ASmart Medical Scribe — Landing Page

Public landing page for distributing ASmart Medical Scribe to end users.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router

## Setup

```bash
npm install
```

## Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Run locally with hot reload |
| `npm run build` | Type-check and build for production (outputs to `dist/`) |
| `npm run preview` | Preview the production build locally |

## Structure

```
src/
  components/   Reusable UI components
  pages/        Route pages
  assets/       Images and static assets
  constants.ts  Shared config/constants
public/         Static files served as-is
```
